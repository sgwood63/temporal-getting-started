# Getting Started with Temporal

I want to get an initial AI based application using the Temporal Cloud.

Install the Temporal Python SDK in a new virtual environment.
Have all the Python work with this application run in the new virtual environment.

Install the Temporal CLI.

Install the Temporal AI Agent https://github.com/temporal-community/temporal-ai-agent

Use my OpenAI key to support the ai-agent.

Create an appropriate CLAUDE.md.

Save the project in a new public Github repo: sgwood/temporal-getting-started.

## Dev Log

Maintain `HISTORY.md` as a running log of all work done in this project. Append an entry whenever you make a meaningful change: what was asked, what decision was made, and what files were affected. This is the persistent record across sessions — treat it like a commit message trail.

When `HISTORY.md` exceeds 500 lines, condense entries older than 30 days into  a summary block at the top titled `## Archived Summary (through [date])`, preserving all recent detailed entries below it.

Never delete the archived summary block, only append to it.
